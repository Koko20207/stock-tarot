# Code of Conduct

## Our Standard

We want this project to stay practical, calm, and welcoming.

Examples of good participation:

- share actionable feedback
- provide reproducible examples
- improve docs for new users
- disagree without personal attacks

Examples of unacceptable behavior:

- harassment or insults
- pressure to provide direct financial advice
- misleading claims of guaranteed profit
- spam, trolling, or hostile review behavior

## Enforcement

Project maintainers may remove contributions or discussion that make the project unsafe, misleading, or hostile.
