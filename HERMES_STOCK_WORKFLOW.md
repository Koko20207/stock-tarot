# HERMES Stock Workflow

This document describes how stock-tarot can evolve from a stock-picking interface into a repeatable research workflow.

## Goal

Separate fast candidate capture from slower, more structured review.

## Workflow

1. Capture a candidate quickly during work hours.
2. Store the candidate in a structured inbox.
3. Review the candidate later with current data.
4. Apply repeatable screening rules.
5. Return research labels instead of trading commands.

## Suggested Research Labels

- `觀察`
- `接近條件`
- `不符合`
- `資料不足`

## Why This Helps

This reduces the common failure mode where a stock idea is noticed quickly, half-remembered later, and then judged inconsistently.

## Future Direction

- candidate inbox schema
- local parser for short capture text
- after-work batch review mode
- signal filtering for noisy price action
