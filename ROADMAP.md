# Roadmap

## Phase 1: Public Workflow Foundation

- document the stock selection logic more clearly
- separate watchlist workflow from direct trading decisions
- explain mobile-first usage and deployment paths
- publish contribution and maintenance rules

## Phase 2: HERMES Workflow Integration

- add a structured candidate inbox format
- support work-hour capture and after-work review
- define stable research labels for stock candidates
- connect signal filtering rules with watchlist review

## Phase 3: Local Tooling

- add a parser for fast capture lines
- add sample candidate datasets
- add lightweight validation scripts
- add reusable JSON output formats

## Phase 4: Quality And Community

- add tests for parser behavior and classification outputs
- add issue templates and examples
- improve release notes and changelog discipline
- publish examples for realistic watchlist review flows
