# Contributing

Thanks for contributing to stock-tarot.

## Good Contribution Areas

- documentation clarity
- mobile usability improvements
- stock workflow examples
- watchlist logic explanations
- local helper scripts
- safer research-oriented analysis flows

## Ground Rules

- keep the project oriented toward research and watchlist review
- do not turn the project into direct trading advice
- prefer repeatable logic over vague intuition
- explain behavior changes with concrete examples
- keep changes easy to review

## Pull Request Checklist

- explain the user problem being solved
- explain why the change improves the workflow
- update docs when behavior changes
- avoid implying guaranteed returns
- keep examples realistic and reproducible

## Safety

This repository should help users organize stock observation and review workflows. It should not claim certainty, automate broker actions, or pressure users into direct buy/sell behavior.
