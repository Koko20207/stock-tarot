# v0.1.0 - Public Workflow Foundation

This release turns `stock-tarot` from a stock observation interface into a more clearly maintained open-source workflow project.

## Highlights

- Added public project maintenance files:
  - `ROADMAP.md`
  - `CONTRIBUTING.md`
  - `LICENSE`
  - `CODE_OF_CONDUCT.md`
  - `CHANGELOG.md`

- Added workflow documentation:
  - `HERMES_STOCK_WORKFLOW.md`
  - `SAMPLE_REVIEW_OUTPUTS.md`

- Added lightweight tooling:
  - `package.json`
  - `scripts/parse_capture.js`
  - `scripts/test_parse_capture.js`
  - `examples/capture_examples.md`

## Why This Release Matters

This version establishes the repository as a maintainable, research-oriented open-source project. It documents how work-hour stock ideas can be captured, reviewed later, and labeled consistently without turning the system into direct trading advice.

## Current Focus

- stock watchlist workflow
- low-base breakout review structure
- after-work batch review ideas
- lightweight note parsing for candidate capture
